## 1. Metric definitions

**OA graded score** — Object-Aligner's deterministic, schema-driven graded list-alignment score in $[0,1]$ (the GEPA reward). A response that fails to decode to valid JSON or violates the schema scores exactly $0$ and is counted as a *failed sample* (`n_zero`). All scores are on their native scale **$[0,1]$** (1 = perfect; never percentages). Means are reported per schema *kind* as the zero-excluded mean (`mean_score_nonzero`); per-cell failed-sample counts and the all-samples mean are omitted by default (enable with `--failed-samples` / `--appendix`). Each run is scored under **every** schema kind of its dataset (so the per-dataset table is also a cross-schema view), with `★` marking the kind the run was optimised on (`primary_kind`). NB some schema kinds are intentionally lenient — e.g. the sentence-ordering *Hungarian* schema is order-insensitive and scores ~1.0 for any permutation — so compare *across the same kind* (column), not across an ablation's own primary kind.

### Task-native leaderboard metrics

Recomputed deterministically from each run's `holdout_scores.jsonl` using the canonical `*_eval.score_corpus` implementations. Datasets not listed here (e.g. SynRA-NL, SynRA-Codex, GraphImg) have no separate leaderboard metric — the OA graded score is their only metric.

**AMR — Bio (USC/ISI)**

- **Smatch F1** — the canonical AMR metric (Cai & Knight 2013): search for the variable alignment between predicted and gold graphs that maximises matched triples (instances, relations, attributes), then micro-averaged F1 over the corpus. Computed with the official `smatch` package; a response that fails to parse to a non-empty graph contributes 0 matched triples (all gold triples become false negatives).

**NATURAL PLAN — Meeting Planning**

- **Solve rate** — official NATURAL PLAN meeting metric: a validator walks the schedule (travel via the distance matrix, per-person availability windows, no duplicates) and counts valid meetings; the example scores 1 iff that count equals the golden plan's optimum. Un-parseable JSON scores 0.

**NATURAL PLAN — Trip Planning**

- **Solve rate** — official NATURAL PLAN trip exact-match: the predicted `(city, days)` sequence must match the gold itinerary for every gold stay, in order (short predictions fail; extra trailing stays are ignored). Un-parseable JSON scores 0.

**PlanBench — Blocksworld**

- **Solve rate** — plan *validity* (PlanBench's official metric, not exact-match): an action sequence scores 1 iff, executed from the initial state under standard IPC Blocksworld semantics, every precondition holds and the goal is reached. Alternative valid orderings also score 1. Un-parseable JSON or a malformed plan scores 0.

**SciERC**

- **Rel (entity-level) F1** — headline coref-aware relation F1: gold mention-pair relations are projected to gold-cluster pairs, predicted clusters are aligned to gold clusters by shared resolved spans, and relations are matched at the cluster level. Micro-averaged; symmetric relations match in either order.
- **Rel+ (entity-level) F1** — as Rel but the argument entity *types* must also match (strict).
- **NER F1** — mention-level span+type micro-F1; this is the PURE / PL-Marker / DyGIE++ “Ent” metric, 1:1. Predicted mention spans are re-anchored to the raw token sequence by first-unused-occurrence case-insensitive match; un-anchorable mentions are dropped.

**Sentence Ordering — arXiv abstracts**

- **PMR (Perfect-Match Ratio)** — fraction of examples whose predicted order exactly matches the single gold order (strict).
- **Kendall's τ** — mean rank correlation between predicted and gold order in $[-1,1]$ (1 identical, −1 reversed). A response that does not parse to a valid permutation of $1..N$ contributes PMR 0, τ 0.

**Sentence Ordering — ROCStories**
